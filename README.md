# Лабораторная работа №2 — Git

## Задачи
1. Калькулятор двух чисел (ветка calculator, fast-forward merge)
2. Определение чётности числа (bugfix-ветка)
3. Факториал числа — рекурсивный и итеративный (merge двух веток)
4. Проверка палиндрома (cherry-pick)

## Освоенные команды Git
- init, add, commit, status, log
- branch, checkout, merge
- cherry-pick, rebase, stash, revert
- работа с конфликтами: в одной задаче, между задачами, в ресурсах
- работа с удалённым репозиторием (remote add, push, pull)
